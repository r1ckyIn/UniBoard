## Overview

UniBoard v2.0 is the end-to-end production foundation: a 10-page Next.js dashboard backed by a FastAPI + Supabase + Railway + Vercel stack with 4 platform adapters (Canvas, Ed Discussion, Ed Lessons, USYD Unit Outline), an AI/MCP layer (Claude Agent + skill system + MCP server), and full production hardening (CI/CD, Sentry, security headers, deploy automation). Built across four declared sub-milestones (M1 Frontend, M2 Backend Core, M3 AI/MCP/Skills, M4 Hardening) plus the v3.0-bridge production phases (29-34, 32.1, 38, 38.1, 38.2).
