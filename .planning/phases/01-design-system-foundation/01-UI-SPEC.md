## Rough.js Configuration (Phase 1 Shared Components)

### RoughCard -- Hand-Drawn Border
Applied to any element with `data-hand-border` attribute.

```javascript
// Configuration object for all card borders:
{
  stroke: '#d0cdc4',
  strokeWidth: 0.8,
  roughness: 1.0,
  bowing: 1,
  fill: 'none'
}
// SVG viewBox: '-4 -4 (w+8) (h+8)' to allow stroke overflow
```

Drawing approach:
1. Wait for two `requestAnimationFrame` cycles (double rAF) to ensure layout is stable
2. Read `el.offsetWidth` and `el.offsetHeight`
3. Create SVG element with class `hand-border-svg`
4. Set `viewBox` to `-4 -4 ${w+8} ${h+8}`
5. Draw `rc.rectangle(0, 0, w, h, opts)` and append to SVG
6. Prepend SVG to element

CSS for the SVG overlay:
```css
.hand-border-svg {
  position: absolute; inset: 0;
  width: 100%; height: 100%;
  pointer-events: none; z-index: 2;
  overflow: visible;
}
```

Auth/setup pages use seed-based determinism: `{ ...opts, seed: 42 }` and redraw borders during height transitions using `requestAnimationFrame` loops.
