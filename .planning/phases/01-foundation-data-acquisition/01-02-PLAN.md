Implement the complete JWT authentication layer and user management endpoints for UniBoard.

Purpose: SC-2 from ROADMAP requires "A user can register with email/password and receive a JWT token; the token authenticates subsequent API requests." This plan builds the security module (password hashing, JWT), auth endpoints (register, login, refresh), user profile endpoints (profile CRUD, platform token storage with encryption), and a health check endpoint. Together with Plan 01-01's database and encryption foundation, this completes the auth infrastructure.

Output: Working auth flow where register -> login -> Bearer token -> access protected endpoints. Platform token storage with AES-256-GCM encryption and immediate API validation. Health check for infrastructure verification.

Create four files that form the auth foundation. These are consumed by route endpoints in Task 2.

**src/security/password.py** -- Password hashing with passlib:
- Import `CryptContext` from `passlib.context`
- Create `pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")`
- `hash_password(password: str) -> str` -- returns bcrypt hash
- `verify_password(plain_password: str, hashed_password: str) -> bool` -- returns match result
- CRITICAL: Use `passlib[bcrypt]`, NOT raw `bcrypt` library directly (passlib handles rounds and auto-upgrade)

**src/security/auth.py** -- JWT creation/validation with PyJWT:
- CRITICAL: `import jwt` (from PyJWT package), NOT `from jose import jwt` (python-jose is abandoned with 8 CVEs -- see PITFALLS.md Pitfall 6)
- Import `OAuth2PasswordBearer` from `fastapi.security`
- Import `get_session` from `src.database`, `User` from `src.models.user`, `get_settings` from `src.config`
- `oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/api/v1/auth/login")`
- `create_access_token(data: dict[str, Any], expires_delta: timedelta | None = None) -> str`:
  - Copy data dict, add `exp` claim as `datetime.now(timezone.utc) + expires_delta` (default: settings.access_token_expire_minutes)
  - Add `type` claim: `"access"`
  - Encode with `jwt.encode(to_encode, settings.secret_key, algorithm="HS256")`
- `create_refresh_token(data: dict[str, Any]) -> str`:
  - Same as access token but with `type: "refresh"` and `expires_delta = timedelta(days=settings.refresh_token_expire_days)`
- `decode_access_token(token: str) -> dict[str, Any]`:
  - `jwt.decode(token, settings.secret_key, algorithms=["HS256"])`
  - Catch `jwt.ExpiredSignatureError` -> raise HTTPException(401, detail="Token expired")
  - Catch `jwt.InvalidTokenError` -> raise HTTPException(401, detail="Invalid token")
- `async def get_current_user(token: str = Depends(oauth2_scheme), session: AsyncSession = Depends(get_session)) -> User`:
  - Decode token, extract `sub` claim (user UUID string)
  - Verify `type` claim is `"access"` (reject refresh tokens used as access tokens)
  - Fetch User from DB via `session.get(User, uuid.UUID(sub))`
  - If no user found, raise HTTPException(401, detail="User not found")
  - Return User object

**src/schemas/auth.py** -- Auth Pydantic v2 schemas:
- Use `model_config = ConfigDict(...)` (NOT `class Config:` -- Pydantic v2 only)
- `RegisterRequest`: email (EmailStr), password (str, min_length=8), display_name (str, min_length=1, max_length=100)
- `RegisterResponse`: user_id (str), email (str), display_name (str)
- `LoginResponse`: access_token (str), refresh_token (str), token_type (str = "bearer"), expires_in (int) -- seconds until access token expires
- `RefreshRequest`: refresh_token (str)

**src/schemas/user.py** -- User profile Pydantic v2 schemas:
- `TokenStatus` -- Pydantic model: status (Literal["active", "invalid", "not_configured"]), platform (str)
- `UserResponse`: id (str), email (str), display_name (str), gpa_target (float | None), gpa_scale (str), tokens (dict with canvas and ed TokenStatus), created_at (datetime)
- `UserUpdateRequest`: display_name (str | None = None), gpa_target (float | None = None), gpa_scale (str | None = None) -- all optional, PATCH semantics
- `TokenConfigRequest`: token (str) -- the raw platform API token
- `TokenConfigResponse`: status (str), platform (str), courses_found (int)
