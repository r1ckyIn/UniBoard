**src/adapters/resilience.py** — Resilience utilities per TRD §14.5 and §14.7:

1. `CircuitState` enum: CLOSED, OPEN, HALF_OPEN.

2. `CircuitBreaker` dataclass:
   - `failure_threshold: int = 5` (5 consecutive failures -> OPEN)
   - `recovery_timeout: float = 60.0` (60s cooldown before HALF_OPEN)
   - `state: CircuitState = CLOSED`
   - `failure_count: int = 0`
   - `last_failure_time: float = 0.0`
   - `record_success()`: reset failure_count to 0, set state to CLOSED.
   - `record_failure()`: increment failure_count, set last_failure_time. If failure_count >= threshold, set OPEN and log warning via structlog.
   - `can_execute() -> bool`: CLOSED -> True. OPEN -> check if elapsed >= recovery_timeout, if so transition to HALF_OPEN and return True, else return False. HALF_OPEN -> True (allow one test request).

3. `CanvasRateLimiter` dataclass:
   - `remaining: float = 700.0` (Canvas gives 700 cost units per 10s window)
   - `min_remaining: float = 50.0` (safety buffer per CONTEXT.md)
   - `update_from_headers(headers: httpx.Headers)`: read `x-rate-limit-remaining` header, update self.remaining.
   - `wait_if_needed()`: if remaining <= min_remaining, asyncio.sleep(2.0) and log warning.

4. `RetryConfig` dataclass:
   - `max_attempts: int = 3`
   - `base_delay: float = 1.0` (exponential: 1s -> 2s -> 4s)
   - `max_delay: float = 30.0`
   - `retryable_statuses: set[int] = {429, 500, 502, 503, 504}`
   - `get_delay(attempt: int) -> float`: min(base_delay * 2^attempt, max_delay)
   - `is_retryable(status_code: int) -> bool`: check against retryable_statuses

5. `async def execute_with_retry(func, retry_config, circuit_breaker) -> httpx.Response`:
   - Loop up to max_attempts. Call func(). If retryable error, check Retry-After header for 429, else use exponential backoff. Record success/failure on circuit breaker. Raise after exhausting retries.

**src/adapters/canvas.py** — CanvasAdapter implementing LMSAdapter:

1. Constructor: `__init__(self, api_token: str, base_url: str = "https://canvas.sydney.edu.au/api/v1")`. Create `httpx.AsyncClient` with base_url, Bearer token header, timeout=30.0. Initialize `CanvasRateLimiter()` and `CircuitBreaker()`.

2. `async _request(self, method: str, path: str, **kwargs) -> httpx.Response`:
   - Check `self._circuit.can_execute()`. If False, raise `UpstreamUnavailableError("Canvas circuit breaker is open")`.
   - Call `await self._rate_limiter.wait_if_needed()`.
   - Execute request via `self._client.request(method, path, **kwargs)`.
   - Call `self._rate_limiter.update_from_headers(response.headers)`.
   - If `response.status_code in (401, 403)`: raise `TokenInvalidError("Canvas token invalid or expired")`.
   - If `response.status_code == 429`: record failure on circuit breaker, parse Retry-After header, raise `RateLimitedError`.
   - If `response.status_code >= 500`: record failure on circuit breaker, raise `UpstreamAPIError`.
   - On success: record success on circuit breaker, return response.
   - Log every request: URL, status code, duration, response size (via structlog).

3. `async _paginate(self, path: str, **kwargs) -> list[dict]`:
   - Follow `Link` header `rel="next"` using regex `<([^>]+)>;\s*rel="next"`.
   - When following pagination, the next URL is absolute — use it directly (not relative to base_url). Handle this by checking if the URL starts with "http" and using `self._client.get(absolute_url)` for subsequent pages.
   - Accumulate all results into a flat list.

4. Methods (all using _paginate or _request):
   - `get_courses()`: GET /courses, params: enrollment_state=active, per_page=100
   - `get_grades(course_id)`: GET /courses/{course_id}/enrollments, params: user_id=self, include[]=current_points
   - `get_assignments(course_id)`: GET /courses/{course_id}/assignments, params: per_page=100
   - `get_modules(course_id)`: GET /courses/{course_id}/modules, params: include[]=items, per_page=100 (CRITICAL: include[]=items to avoid N+1 per Pitfall 1)
   - `get_tabs(course_id)`: GET /courses/{course_id}/tabs
   - `get_external_tool(course_id, tool_id)`: GET /courses/{course_id}/external_tools/{tool_id}
   - `validate_token()`: GET /users/self, return True if 200, False otherwise (catch exceptions)

5. `async close()`: `await self._client.aclose()`

6. Define custom exceptions in the module or import from a shared errors module:
   - `TokenInvalidError(Exception)` — 401/403 from upstream
   - `UpstreamUnavailableError(Exception)` — circuit breaker open
   - `UpstreamAPIError(Exception)` — 5xx from upstream
   - `RateLimitedError(Exception)` — 429 from upstream
