**Every hook file follows this structure:**
```typescript
import { queryOptions, useQuery, useMutation, useQueryClient } from "@tanstack/react-query";
import { api } from "@/lib/api/client";
import type { paths } from "@/lib/api/types.gen";

// 1. Response type aliases (extract from generated paths)
type XxxResponse = paths["/endpoint"]["get"]["responses"]["200"]["content"]["application/json"];

// 2. Query key factory (hierarchical, const assertions)
export const xxxKeys = {
  all: ["xxx"] as const,
  lists: () => [...xxxKeys.all, "list"] as const,
  list: (filters?: Record<string, unknown>) => [...xxxKeys.lists(), filters] as const,
  details: () => [...xxxKeys.all, "detail"] as const,
  detail: (id: string) => [...xxxKeys.details(), id] as const,
};

// 3. queryOptions factory (reusable between useQuery and queryClient.prefetch)
export const xxxOptions = {
  list: (filters?: Record<string, unknown>) =>
    queryOptions({
      queryKey: xxxKeys.list(filters),
      queryFn: () => api.get("endpoint", { searchParams: filters ?? {} }).json<XxxResponse>(),
    }),
};

// 4. Thin hook wrappers
export function useXxx(filters?: Record<string, unknown>) {
  return useQuery(xxxOptions.list(filters));
}
```

**IMPORTANT ky path rules:**
- NO leading slash: use `api.get("courses")` not `api.get("/courses")`
- For POST with JSON body: `api.post("gpa/predict", { json: body }).json<T>()`
- For query params: `api.get("courses", { searchParams: { semester: "2026-S1" } }).json<T>()`
- For dynamic paths: `api.get(\`courses/${id}\`).json<T>()`

**Note on generated types:** The response type from `types.gen.d.ts` includes the full envelope `{ data: ..., meta: ... }`. When the hook returns, calling code accesses `queryResult.data.data` for the payload and `queryResult.data.meta` for metadata.

Create these 12 hook files:

**1. `frontend/hooks/use-auth.ts`** — Auth mutations (no query keys needed, mutations only):
- `useLogin()`: `useMutation` calling `api.post("auth/login", { json: { email, password } })`. On success, call `useAuthStore.getState().setAuth(tokens, user)`. Access store via `getState()` (not the hook) since mutation callbacks run outside render.
- `useRegister()`: `useMutation` calling `api.post("auth/register", { json: { email, password, display_name } })`.
- `useLogout()`: `useMutation` calling `api.post("auth/logout", { json: { refresh_token } })`. On success, call `useAuthStore.getState().clearAuth()` and `queryClient.clear()` to wipe all cached data.
- `useRefreshToken()`: `useMutation` calling `api.post("auth/refresh", { json: { refresh_token } })`. On success, update tokens in auth store.
