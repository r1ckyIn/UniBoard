4. **src/services/gpa.py** -- Create GPAService:

   ```python
   """GPA/WAM calculation service with what-if simulation and target path planning."""
   from __future__ import annotations
   import uuid
   from decimal import Decimal, ROUND_HALF_UP
   from sqlalchemy import select
   from sqlalchemy.ext.asyncio import AsyncSession
   from sqlalchemy.orm import selectinload
   from src.models.course import Course
   from src.models.grade import Grade
   from src.models.whatif import WhatIfScenario
   from src.schemas.common import NotFoundError
   from src.schemas.gpa import (
       AssessmentDetail, AssessmentTarget, CourseSummary, CourseDetailResponse,
       GPASummaryResponse, SemesterTrend, TargetPathResponse, TargetRequest,
       TrendResponse, WhatIfCreateRequest, WhatIfScenarioResponse, WhatIfScore,
   )
   ```

   **Constants:**
   ```python
   GRADE_BANDS: list[tuple[Decimal, str, int]] = [
       (Decimal("85"), "HD", 7),
       (Decimal("75"), "D", 6),
       (Decimal("65"), "CR", 5),
       (Decimal("50"), "P", 4),
       (Decimal("0"), "F", 0),
   ]
   ```

   **Class GPAService:**
   - `__init__(self, session: AsyncSession) -> None`
   - Store session as `self._session`

   **Pure calculation helpers (all use Decimal):**
   - `_mark_to_grade_band(mark: Decimal) -> tuple[str, int]` -- Iterate GRADE_BANDS, return first match where mark >= threshold. Return ("F", 0) for marks < 50.
   - `_calculate_course_wam(grades: list[Grade]) -> tuple[Decimal, Decimal]` -- Returns (course_wam, pct_assessed). For graded assessments: course_wam = sum(score/max_score * weight * 100) / sum(weight_of_graded). pct_assessed = sum(weight_of_graded) / sum(all_weights) * 100. Use Decimal for all arithmetic. Convert float to Decimal via `Decimal(str(value))`.
   - `_calculate_cumulative_wam(courses_data: list[tuple[Decimal, int]]) -> Decimal` -- WAM = sum(mark * cp) / sum(cp). Input is list of (course_wam, credit_points). Returns Decimal quantized to 2 places.
   - `_calculate_cumulative_gpa(courses_data: list[tuple[Decimal, int]]) -> Decimal` -- GPA = sum(gpa_point * cp) / sum(cp). Map each course_wam to gpa_point, then weighted average. Returns Decimal quantized to 2 places.

   **Service methods:**

   a. `async def get_summary(self, user_id: uuid.UUID) -> GPASummaryResponse`:
      - Query all courses for user with `selectinload(Course.grades)`
      - For each course: calculate WAM, grade band, pct_assessed using helpers
      - Calculate cumulative WAM and GPA across all courses weighted by credit_points
      - Return GPASummaryResponse

   b. `async def get_course_detail(self, user_id: uuid.UUID, course_id: uuid.UUID) -> CourseDetailResponse`:
      - Query single course with grades and unit_outlines loaded
      - If not found or wrong user, raise NotFoundError
      - Determine weight_source: if unit_outlines exist with valid assessments -> "unit_outline", elif grading_weights JSON -> "canvas_assignment_groups", else "unknown"
      - Return CourseDetailResponse with full assessment breakdown

   c. `async def simulate(self, user_id: uuid.UUID, request: WhatIfCreateRequest) -> WhatIfScenarioResponse`:
      - Query all courses with grades for the user
      - Apply hypothetical scores: for each WhatIfScore, find the matching assessment by ID and override its score
      - Recalculate WAM and GPA with the modified scores
      - Create WhatIfScenario row in database with JSONB scores_json
      - Return WhatIfScenarioResponse

   d. `async def list_scenarios(self, user_id: uuid.UUID) -> list[WhatIfScenarioResponse]`:
      - Query WhatIfScenario where user_id matches, order by created_at desc
      - Return list of WhatIfScenarioResponse

   e. `async def calculate_target_path(self, user_id: uuid.UUID, request: TargetRequest) -> TargetPathResponse`:
      - Query all courses with grades for the user
      - Identify ungraded assessments (score is None)
      - Calculate current weighted mark total and total credit points
      - **Uniform mode**: Calculate the single score X needed for all remaining assessments such that final WAM = target. X = (target * total_cp - current_weighted) / remaining_weighted. If X > 100, target is unreachable.
      - **Smart mode**: Sort ungraded assessments by credit_points DESC (high-cp courses get lower required scores). Distribute needed marks proportionally.
      - Calculate max_achievable_wam (assume 100 for all remaining)
      - Return TargetPathResponse with is_achievable, required_scores, max_achievable_wam

   f. `async def get_trend(self, user_id: uuid.UUID) -> TrendResponse`:
      - Query all courses with grades, group by semester
      - Sort semesters chronologically
      - For each semester: calculate semester WAM/GPA and running cumulative WAM/GPA
      - Return TrendResponse

   CRITICAL: All Decimal conversions use `Decimal(str(float_value))` -- NEVER `Decimal(float_value)` which inherits float imprecision. All final results use `.quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)`.
