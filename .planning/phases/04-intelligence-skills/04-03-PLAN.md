    |-------|------|-------------|
    | Canvas API | rules/canvas-api.md | Fetching courses, grades, assignments, modules |

    ## Files

    - `src/adapters/canvas.py` — CanvasAdapter

    - Canvas rate limiting uses X-Rate-Limit-Remaining header (sliding window)
    - Ed API is undocumented; field names verified in TRD SS9.4
    - Canvas Modules API requires `include[]=items` to avoid N+1
    - zsh export may escape special chars in tokens; use inline in curl
