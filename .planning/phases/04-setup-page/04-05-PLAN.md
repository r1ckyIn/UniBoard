    ```
    <div ref={containerRef} bg-card-bg rounded-card shadow-card padding>
      <svg inset-0 /> <!-- rough border hidden by bg at same edge -->
      <div z-1>{children}</div>
    </div>
    ```

    ```
    <div ref={containerRef} overflow-visible p-[10px] relative> <!-- OUTER: padding gap, NO bg, NO rounded -->
      <svg inset-0 /> <!-- rough border drawn on page background, wobble visible -->
      <div bg-card-bg rounded-card shadow-card overflow-hidden padding> <!-- INNER: has bg + content -->
        <div z-1>{children}</div>
      </div>
    </div>
    ```

    Specific changes:
    1. The outer `containerRef` div should have: `relative overflow-visible p-[10px]` and NO `bg-card-bg`, NO `rounded-card`, NO `shadow-card`
    2. Move `bg-card-bg rounded-card shadow-card overflow-hidden` to a NEW inner wrapper div
    3. The `padding` prop applies to the inner wrapper (not outer)
    4. The hover classes (`hover:shadow-card-hover hover:-translate-y-px`) apply to the OUTER wrapper (so the whole card lifts on hover)
    5. The `className` prop applies to the outer wrapper
    6. Keep SVG positioning as `absolute inset-0` on the outer wrapper (no change)
    7. Keep all ResizeObserver and drawBorder logic unchanged (it reads from containerRef which is the outer wrapper)
    8. The rough.js rectangle will now be drawn with a 10px gap from the inner content background, making the hand-drawn wobble clearly visible against the cream page background

    This matches the prototype's `.setup-card` (outer, padding:10px, no bg) + `.setup-card-inner` (bg, padding) structure.

    **Changes to SetupPage.tsx:**

    1. Add imports: `useSearchParams` from `next/navigation`, `useRouter` and `usePathname` from `@/lib/i18n/navigation`
    2. Wrap the component body in a Suspense-aware pattern (Next.js 15 requires Suspense boundary for useSearchParams in static builds -- the existing page.tsx already has a `<Suspense>` wrapper from Phase 04-01, so SetupPage can safely use useSearchParams)
    3. Read initial step from URL: `const searchParams = useSearchParams()` then parse `searchParams.get("step")` to get initial value. Valid values: "1", "2", "3", "success". Default to 1 if missing/invalid.
    4. Replace `useState<1 | 2 | 3 | "success">(1)` with `useState<1 | 2 | 3 | "success">(initialStep)` where `initialStep` is parsed from URL
    5. Create a `setStepWithUrl` helper that:
       - Calls `setStep(newStep)`
       - Updates URL: `router.replace(\`${pathname}?step=${newStep}\`, { scroll: false })` using next-intl router
       - This way LanguageSwitcher's `window.location.search` will pick up `?step=N` and preserve it during locale switch
    6. Replace all `setStep(...)` calls with `setStepWithUrl(...)`:
       - `onNext={() => setStepWithUrl(2)}`
       - `onBack={() => setStepWithUrl(1)}`
       - `onNext={() => setStepWithUrl(3)}`
       - `onBack={() => setStepWithUrl(2)}`
       - `onSuccess={() => setStepWithUrl("success")}`

    **Important:** Use `router` and `pathname` from `@/lib/i18n/navigation` (not from `next/navigation`) so the locale prefix is handled correctly. The `useSearchParams` hook must come from `next/navigation` (not next-intl).
