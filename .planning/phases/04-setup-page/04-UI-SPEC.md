## Layout Contract

### Page Structure
- Full-page centered layout: min-height 100vh, flexbox center both axes
- Page padding: 40px 20px
- Container max-width: 640px
- No AppShell, no sidebar, no header (standalone onboarding)
- Route: `/[locale]/setup` in `(auth)` route group

### Layering (z-index)
| Layer | z-index | Element |
|-------|---------|---------|
| Paper grain | 9999 | body::before (pointer-events: none) |
| Rough.js border | 2 | SVG overlay on card |
| Content | 1 | Card inner content |
| Background doodles | 0 | AuthDoodles SVG (fixed, full-screen) |
| Ruled lines | -1 | body::after |

### Step Indicator
- 3 circles (34px diameter) + 2 connecting lines (48px wide, 2px height, 8px horizontal margin)
- Centered horizontally, 32px below top of container
- Circle states:
  - Active: bg orange (#d97757), white text, white number
  - Completed: bg green (#788c5d), white check icon (16px), number hidden
  - Upcoming: transparent bg, 2px solid card-border, text-3 number
- Line states:
  - Completed: bg green (#788c5d)
  - Upcoming: bg card-border (#e8e5dd)
- Display-only: NOT clickable (CONTEXT.md decision)

### Card
- RoughCard component with disableHover={true}
- Inner padding: 40px 36px (desktop), 28px 20px (mobile < 680px)
- Rough.js border: stroke #d0cdc4, strokeWidth 0.8, roughness 1.0, bowing 1, seed 42
- Steps wrapper: relative overflow hidden, height transitions via Motion

### Responsive Breakpoint
- Single breakpoint at 680px (max-width)
- Below 680px: card padding reduces, welcome features stack vertically (column layout)
- Feature badge items: column with row inner layout (icon + label side by side)

## Interaction Contract

### Step Navigation Flow

```
Step 1 (Welcome) → "Get Started" → Step 2 (Tutorial)
Step 2 (Tutorial) → "Back" → Step 1 | "I have my tokens" → Step 3
Step 3 (Paste) → "Back" → Step 2 | "Validate & Connect" → Validation → Success
Success → "Go to Dashboard" → /dashboard
```

### Step Transitions (Motion/AnimatePresence)
- Crossfade with height morphing between steps
- Outgoing step: opacity 0, position absolute
- Incoming step: opacity 1, position relative (flow)
- Height transition: 0.4s cubic-bezier(.4,0,.2,1)
- Opacity transition: 0.3s ease
- RoughCard ResizeObserver redraws border during height animation (existing burst pattern)

### Entrance Animation (page load)
- AuthDoodles: fade-in (CSS animate-fade-in)
- Step indicator: slideUp with delay 0.04s (AnimatedEntry delay={1})
- Card: slideUp with delay 0.12s (AnimatedEntry delay={2})
- slideUp: from opacity:0 translateY(18px) to opacity:1 translateY(0), 0.6s cubic-bezier(.16,1,.3,1)

### Guide Card Collapse/Expand
- Both cards default expanded (NOT accordion -- both open simultaneously)
- Independent toggle via header click (chevron-down icon rotates -90deg when collapsed)
- Height animation: 0.35s cubic-bezier(.4,0,.2,1)
- Opacity animation: 0.25s ease (fade during collapse)
- RoughCard border redraws during transition via ResizeObserver

### Token Validation Sequence
1. User clicks "Validate & Connect"
2. Button disables, text changes to "Validating..."
3. Canvas token validated first (format check: numeric string, ~70 chars)
   - Pass: input border green, check-circle appears
   - Fail: input border red, x-circle appears, error text shows, button re-enables, STOP
4. Wait 0.8s
5. Ed token validated (format check: shorter alphanumeric string)
   - Pass: input border green, check-circle appears
   - Fail: input border red, x-circle appears, error text shows, button re-enables, STOP
6. Both pass: wait 0.5s, transition to success state

### Success State Sequence
1. Step indicator: all 3 circles completed (green), both lines completed (green)
2. Steps wrapper fades out, success state fades in
3. Success check circle: 64px, green-soft bg, green check icon 30px
4. Title: "You're all set!"
5. Sync spinner (14px, card-border + orange-top border, 0.8s spin) + "Syncing your data..." (italic, text-3)
6. Call mock sync API: POST /api/v1/sync/trigger
7. After ~3s: spinner replaced by green check + "{N} courses synced successfully" (green, weight 600, non-italic)
   - Display actual mock course codes from fixture data: COMP2017, COMP3221, STAT2011, INFO2222, MATH1005
8. "Go to Dashboard" button: primary wide, layout-dashboard icon, navigates to /[locale]/dashboard
9. State update: useAuthStore.setTokenConfigured(true)
10. Toast on dashboard arrival: "Welcome! Your accounts are connected."

### Access Control
- Unauthenticated users → redirect to /[locale]/auth
- Already-configured users (tokenConfigured === true) → redirect to /[locale]/dashboard
- Guard lives in SetupGuard component (extends AuthGuard pattern)
