"use client" component.

Props:
```typescript
interface AssessmentWeight {

  weight: number;
  status: "graded" | "submitted" | "upcoming";
}

interface AssessmentDonutProps {

  courseColor: string;          // Primary course color for single-course rendering
  courseCode: string;           // For display in badge
}
```

Per UI-SPEC Assessment Weights Donut section:
- Wrapper: RoughCard with title "Assessment Weights" (t("donut.title")), badge showing courseCode (dynamic)
- Card title: flex between, Heading role, 600 weight, PieChart icon (lucide) 16px orange
- Badge: Small role, 600, px-2 py-px, 4px radius, course-color-soft bg, course-color text

**Donut rendering with Rough.js:**
- SVG viewBox="0 0 360 300"
- Use rough.svg() to draw arcs for each weight segment
- Donut radii: outer 95px (so diameter 190), inner 55px (so ring width is 40px)
- Center: cx=180, cy=150
- Start angle at -PI/2 (top of circle)
- For each segment, compute start and end angles from cumulative weights
- Use rough.arc(cx, cy, outerR*2, outerR*2, startAngle, endAngle, false, options)
- Segment options: stroke=segmentColor, strokeWidth = outerR - innerR = 40, roughness 1.5, fill=segmentColor, fillStyle "cross-hatch", fillWeight 1.8, seed 42 + index
- Segment colors: distribute from the course palette. If only one course, use variations of courseColor (darken/lighten for each segment). Simple approach: use a fixed palette of 5 segment colors based on the course's brand color, varying saturation/lightness.
  - Graded segments: full opacity of their assigned color
  - Upcoming segments: lighter/desaturated version

**Highlighted segment:**
- When `highlightType` matches a segment's `name`:
  - Increased fillWeight 2.5 (from 1.8)
  - strokeWidth 2 (from normal)
  - Slightly separated outward by 4px (translate the arc center outward along bisecting angle)

**Leader lines:**
- For each segment, draw a leader line from the midpoint of the arc to a label:
  - Start at outerR + 14px from center along midpoint angle
  - Elbow at outerR + 42px
  - Tail extends 30px horizontally
- Labels: percentage in Source Serif 4, 15px, 600 weight, color-matched. Assessment name in Inter, 12px, text-2
- Position labels on the left or right side depending on their angle (left half vs right half of circle)

**Converge entry animation:**
Per UI-SPEC: segments start separated/exploded outward, then converge smoothly toward center to form complete donut. Duration 0.8s, easing cubic-bezier(.16,1,.3,1).

Implementation approach: Use requestAnimationFrame-based animation.
- Initial state: each segment center is offset outward by 20px along its midpoint angle
- Over 0.8s (with cubic-bezier easing), lerp the offset from 20px to 0px
- Apply the offset as a transform on each segment's group element
- Use a `useEffect` triggered on component mount (or when weights change) to start the animation
- Use CSS transition on group transform for simplicity: set initial transform, then in next frame remove it

**Empty state:**
- When weights array is empty, show centered text instead of donut:
  - Heading: t("donut.empty.heading") = "No upcoming deadlines", Heading role, 600, text-2, mb-2
  - Body: t("donut.empty.body"), Body role, text-3

This component MUST be wrapped with `withClientOnly()` when used in parent because it imports roughjs.
