**Gap 9 — Hero annotations stagger (one-by-one):**

The prototype uses `RoughNotation.annotationGroup([a1, a2, a3]).show()` with a 900ms delay (prototype line 1119-1138). The `annotationGroup` API shows annotations one after another — each waits for the previous to finish before starting. The current React implementation shows all annotations simultaneously by setting `showAnnotations = true` in a single state change at 900ms.

1. In `HeroSection.tsx`, replace the single `showAnnotations` boolean state with three separate boolean states for staggered reveal:
   ```
   const [showUnderline, setShowUnderline] = useState(false);
   const [showCircle, setShowCircle] = useState(false);
   const [showHighlight, setShowHighlight] = useState(false);
   ```

2. Replace the single setTimeout with a staggered sequence matching the prototype timing:
   - Annotations start after 900ms delay (matching prototype)
   - Underline (weekday): show at 900ms, duration 600ms
   - Circle (week number): show at 900ms + 600ms = 1500ms, duration 800ms
   - Highlight (encouragement): show at 1500ms + 800ms = 2300ms, duration 1000ms

   ```
   useEffect(() => {
     const t1 = setTimeout(() => setShowUnderline(true), 900);
     const t2 = setTimeout(() => setShowCircle(true), 1500);
     const t3 = setTimeout(() => setShowHighlight(true), 2300);
     return () => { clearTimeout(t1); clearTimeout(t2); clearTimeout(t3); };
   }, []);
   ```

3. Pass the individual show states to the respective `RoughNotationWrapper` components:
   - Weekday underline: `show={showUnderline}`
   - Week circle: `show={showCircle}`
   - Encouragement highlight: `show={showHighlight}`
