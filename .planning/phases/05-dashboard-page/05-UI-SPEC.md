## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Icon gaps, minor inline offsets, button margin-left |
| sm | 8px | Header-right gap, stat-label margin-bottom, profile-stats gap, calendar grid gap, inline badge padding |
| md | 16px | Card-header margin-bottom, profile-stats margin-top, calendar card padding (16px 20px), activity card padding, table cell padding (16px 12px) |
| lg | 24px | Profile card padding (24px 20px), section spacing |
| xl | 32px | Content-area padding (28px→32px snapped), header horizontal padding, step-circle references |
| 2xl | 48px | Hero horizontal padding (48px) |
| 3xl | 64px | Page-level vertical breathing room |

Exceptions (multiples of 4, outside standard set, with justification):

- 12px: Table cell horizontal padding (12px), sidebar-logo gap, avatar-panel item gap -- tighter than 16px for dense tabular/compact UI elements
- 20px: Stat card vertical padding (20px 24px), profile card horizontal padding, calendar card horizontal padding, right-panel gap -- intermediate between 16px and 24px for medium-density card interiors
- 28px: Content-area padding (28px vertical), right-panel sticky top offset calc(header + 28px) -- prototype-specific layout dimension that preserves visual rhythm between header and content
- 36px: Header button size (36px square) -- fixed interactive element size
- 44px: Touch target minimum for header dropdown items (WCAG touch target guideline)
- 52px: Profile avatar size (54px→52px snapped) -- fixed brand element, single instance
- 56px: Header height (var(--spacing-header-h)) -- established layout constant from Phase 01

## Typography

4 declared content sizes + 2 brand-fixed exceptions:

| Role | Size | Weight | Line Height | Font Family | Usage |
|------|------|--------|-------------|-------------|-------|
| Display | 28px | 600 | 1.15 | Source Serif 4 | Hero greeting (2.8rem at 15px base ≈ 42px, but constrained to Display role -- see Brand Exception below), stat-value (2rem ≈ 30px, mapped to Display) |
| Heading | 16px | 600 | 1.4 | Source Serif 4 | Card titles (0.95rem), calendar month name, profile name, dropdown-title, header brand |
| Body | 12px | 400 | 1.5 | Inter | Table cells (0.82rem), stat-sub (0.78rem), activity text (0.76rem), dropdown text (0.78rem), deadline name (0.84rem), profile detail (0.76rem), hero date (1.25rem→mapped to Body at larger contextual size) |
| Small | 10px | 600 | 1.4 | Inter | Stat-label (0.74rem), table headers (0.7rem), grade badges (0.7rem), calendar headers (0.62rem), calendar days (0.74rem), activity time (0.66rem), target badges (0.7rem), predict link (0.68rem), pstat-label (0.66rem) |

**NOTE:** The prototype uses `html { font-size: 15px }` as base, so all rem values are relative to 15px. The 4 roles above consolidate the prototype's ~15 distinct rem values into 4 bands:
- **Display band** (1.0rem+ serif): 2.8rem greeting, 2rem stat values, 1.12rem pstat values, 1.05rem earned cells
- **Heading band** (0.88-0.95rem serif): card titles, month names, profile names, dropdown titles
- **Body band** (0.76-0.84rem sans): table data, activity text, stat descriptions, deadline names, dropdown text
- **Small band** (0.62-0.74rem sans): labels, badges, table headers, calendar cells, timestamps

Brand-fixed exceptions (outside typographic scale):
- Hero greeting: 2.8rem (42px at 15px base), weight 700, Source Serif 4 -- single hero element, significantly larger than any content text, letter-spacing -0.02em
- Hero date: 1.25rem (18.75px), weight 400, Inter -- hero-specific contextual size between Display and Heading
- Hero encouragement: 1.15rem (17.25px), weight 400, Inter, italic -- hero-specific, pairs with date line

Font weights: 400 (regular) and 600 (semibold) only. Exception: 700 used in hero greeting and stat values (Source Serif 4 Display role only -- brand emphasis).

## Layout Contract

### Page Structure
- Uses AppShell layout (inherited from Phase 01): Sidebar (68px collapsed, 224px on hover) + main-wrapper + RightPanel (300px sticky)
- Route: `/[locale]/(dashboard)/page.tsx` -- uses existing `(dashboard)` route group with AppShell layout
- Content area: flex row, padding 28px 32px, gap 28px
- Main content: flex column, gap 24px (snapped from 22px)
- Right panel: sticky top calc(header-h + 28px), max-height calc(100vh - header-h - 56px), overflow-y auto, gap 20px

### Section Order (vertical, within main-content)
1. Hero section (full viewport height minus header)
2. Stats row (3-column grid, scroll anchor)
3. Course Grades card
4. Bottom row (2-column grid: Deadlines + Assessment Weights)

### Responsive Breakpoints
- `max-width: 1200px` (xl): Right panel hidden
- `max-width: 900px`: Stats row and bottom row collapse to single column, content padding 20px 16px, hero min-height 50vh with 40px 24px 32px padding, hero greeting 2rem

## Interaction Contract

### Hero Section

| Interaction | Behavior |
|-------------|----------|
| Page load | Motion spring staggered entrance: doodles fadeIn (0s) -> greeting slideUp (0.1s) -> date slideUp (0.35s) -> encouragement slideUp (0.6s) -> scroll prompt slideUp (1.0s) |
| Scroll prompt click | Smooth scroll to Stats Row (`#dashboard-start`), scroll-margin-top: calc(header-h + 20px) |
| Scroll down | Hero text parallax fade-out: opacity decreases as user scrolls past hero section, data cards take visual priority |
| Rough Notation | Group show at 0.9s delay: underline on weekday (orange), circle on "Week N" (blue), highlight on emotional phrase (orange, 10% opacity) |
| Scroll prompt arrow | gentleBob animation: translateY(0 <-> 5px), 3s ease-in-out infinite |

### Stats Row

| Interaction | Behavior |
|-------------|----------|
| Display | Static values, no countUp animation (CONTEXT.md decision) |
| Click | Not clickable, display-only (CONTEXT.md decision) |
| WAM card annotation | Rough Notation circle on WAM value, orange, strokeWidth 1.2, padding 10, show at 2.2s delay |

### Course Grades Table

| Interaction | Behavior |
|-------------|----------|
| Row hover | Background rgba(217,119,87,.03), "predict ->" link fades from opacity 0 to 1 (0.4s ease) |
| Row hover earned-cell | Rough Notation circle annotation appears in course-specific color |
| "predict ->" click | Navigate to `/[locale]/predict?course={courseId}` (Phase 9, may not exist yet) |
| Row click | Navigate to `/[locale]/courses/{courseId}` (Phase 7, may not exist yet) |

### Deadlines + Donut Linkage

| Interaction | Behavior |
|-------------|----------|
| Default state | Donut shows weights for the course owning the nearest upcoming deadline |
| Deadline hover | translateX(4px) micro-displacement, 0.15s ease |
| Deadline click | Switches donut to show clicked deadline's course weights; the weight segment matching the deadline's assessment type is highlighted (brighter fill, thicker stroke) |
| "see details" button | Positioned left of remaining-days badge. Navigates to `/[locale]/deadlines?id={deadlineId}` (Phase 8) |
| Donut entry animation | Segments start separated/exploded outward, then converge smoothly toward center to form complete donut. Duration 0.8s, easing cubic-bezier(.16,1,.3,1) |
| Empty state (no deadlines) | Donut shows placeholder text: "No upcoming deadlines" |

### Right Panel

#### Profile Card
| Interaction | Behavior |
|-------------|----------|
| Display | Avatar (gradient orange, user initials), name, faculty/program name (e.g., "Bachelor of Science"), semester, course count, credit points |
| Data source | Auth store (name, email) + user profile hook (faculty) + courses hook (count, credits) |

#### Mini Calendar
| Interaction | Behavior |
|-------------|----------|
| Month navigation | Left/right chevron arrows switch displayed month |
| Deadline dots | Dates with deadlines show orange-tinted background. Color depth scales with cumulative assessment weight of that day's deadlines |
| Today | Solid orange bg, white text, weight 600 |
| Date click | Navigate to `/[locale]/deadlines?date={YYYY-MM-DD}` (Phase 8) |

#### Recent Activity
| Interaction | Behavior |
|-------------|----------|
| Display | 4-5 most recent items with color-coded icons (grade=green, discussion=blue, deadline=orange) |
| Item click | Opens ExternalLinkDialog: "Open external link?" with URL preview. Confirm opens URL in new tab |

### Header Dropdowns

| Interaction | Behavior |
|-------------|----------|
| Notification bell click | Toggle NotificationPanel. dropIn animation (0.25s). Arrow notch at top-right |
| Avatar click | Toggle AvatarMenu. dropIn animation (0.25s). Arrow notch at top-right |
| Click outside | Close any open dropdown |
| Notification unread dot | 7px orange circle, 1.5px card-bg border, positioned top-right of bell button |
| "View all notifications" | Navigate to notifications page (future) |
| Avatar menu items | Profile -> `/settings`, Settings -> `/settings`, API Tokens -> `/setup`, Log out -> auth logout |

### Loading & Error States

| State | Behavior |
|-------|----------|
| Loading | Per-section independent: warm-toned skeleton cards matching paper texture aesthetic. Skeleton bg: linear-gradient between card-bg and card-bg-hover with shimmer animation |
| Error | In-card friendly message + retry button. No full-page error. Each section (stats, grades, deadlines, donut, profile, calendar, activity) handles errors independently |
| Hero | Loads first (greeting from auth store, no API call needed for name/time-of-day). Encouragement text loads with data |

### Entrance Animations

| Section | Type | Timing |
|---------|------|--------|
| Hero content | Motion spring, slideUp 0.7s cubic-bezier(.16,1,.3,1) | Staggered: 0.1s, 0.35s, 0.6s, 1.0s |
| Content sections | CSS slideUp 0.6s cubic-bezier(.16,1,.3,1) | d1: 0.04s, d2: 0.09s, d3: 0.14s, d4: 0.19s, d5: 0.28s, d6: 0.38s, d7: 0.48s, d8: 0.56s, d9: 0.64s, d10: 0.72s |
| Donut | Custom converge animation (segments exploded -> centered) | After content slideUp, 0.8s duration |
| Rough Notation (hero) | Group show | 0.9s delay |
| Rough Notation (WAM) | Circle annotation | 2.2s delay |

## Encouragement Text Interface

The encouragement text system must be designed as a pluggable provider:

```typescript
interface ActivitySummary {
  completedDeadlinesLast7Days: number;
  recentCompletedItems: string[];  // e.g., ["COMP2017 Lab 4", "STAT2011 Quiz"]
}

interface EncouragementText {
  message: string;         // Full encouragement text
  highlightPhrase: string; // The phrase to apply Rough Notation highlight on
}

type EncouragementProvider = (activity: ActivitySummary) => EncouragementText;
```

Mock implementation provides 3-5 hardcoded messages. The interface allows the user to later maintain a curated catalog.

## Accessibility Notes

- Hero greeting uses `<h1>` element for page title
- Stats cards use `aria-label` describing the metric (e.g., "Current WAM: 78.5, Distinction")
- Course grades table uses proper `<table>`, `<thead>`, `<th scope="col">`, `<tbody>` semantics
- "predict ->" link has `aria-label="Predict {courseCode} grade"` for context
- Deadline items have `role="button"` and `aria-label` describing the interaction
- "see details" has `aria-label="See details for {assignmentName}"`
- ExternalLinkDialog uses `<dialog>` element or equivalent accessible modal pattern with focus trap
- Calendar navigation buttons have `aria-label="Previous month"` / `"Next month"`
- Calendar days with deadlines have `aria-label="{date}, {N} deadlines"`
- Notification panel has `aria-label="Notifications"` and items have role="listitem"
- Avatar menu has `aria-haspopup="true"` and `aria-expanded` state
- Skeleton cards use `aria-busy="true"` and `aria-label="Loading"`
- All color contrast ratios meet WCAG AA (verified in DESIGN_SYSTEM.md)
- Tab order follows visual flow: hero -> stats -> grades -> deadlines -> donut -> right panel
