**Structure (two-layer card, NOT reusing RoughCard):**

1. **Outer div** (the card container):
   - `ref={containerRef}` for ResizeObserver
   - `onClick` handler: `router.push(\`/courses/\${id}\`)`
   - `cursor-pointer relative overflow-visible`
   - `p-[6px]` (6px padding per prototype, NOT the default 10px from RoughCard)
   - `transition-transform duration-[0.28s] ease-[cubic-bezier(.4,0,.2,1)]`
   - `hover:-translate-y-[3px]`

2. **SVG hand-drawn border** (absolute positioned over outer div):
   - Same pattern as RoughCard: `rough.svg().rectangle()` with options: `{ stroke: "#d0cdc4", strokeWidth: 0.8, roughness: 1.0, bowing: 1, fill: "none", seed: 42 }`
   - viewBox: `-4 -4 ${width+8} ${height+8}`
   - className: `absolute inset-0 w-full h-full pointer-events-none z-[10] overflow-visible`
   - Use ResizeObserver with rAF burst pattern (copy from RoughCard: 400ms burst duration, cancelAnimationFrame cleanup)
   - Double rAF on mount for stable initial draw

3. **Inner div** (card content):
   - `bg-[#f6f5f0] overflow-hidden` (card-bg color, overflow hidden for banner clipping)
   - NO border-radius (rough border IS the visual border)
   - Shadow: `shadow-[0_1px_3px_rgba(20,20,19,0.04),0_4px_14px_rgba(20,20,19,0.025)]`

4. **Banner section** (inside inner div):
