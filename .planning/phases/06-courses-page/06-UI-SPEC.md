### Banner Doodle Decorations (5 patterns)

All doodles use white semi-transparent strokes on the colored banner. Each card gets a different pattern based on its index (`i % 5`).

**Pattern 0 — Circle + Sparkle (top-right):**
```javascript
rc.circle(220, 30, 40, { stroke: "rgba(255,255,255,.3)", strokeWidth: 2, roughness: 2.5, fill: "none" });
rc.line(260, 50, 280, 50, { stroke: "rgba(255,255,255,.25)", strokeWidth: 2, roughness: 2 });
rc.line(270, 40, 270, 60, { stroke: "rgba(255,255,255,.25)", strokeWidth: 2, roughness: 2 });
```

**Pattern 1 — Wave line + small circle:**
```javascript
rc.path("M 180 20 Q 200 8, 220 20 Q 240 32, 260 20 Q 280 8, 300 20", { stroke: "rgba(255,255,255,.25)", strokeWidth: 2, roughness: 2 });
rc.circle(290, 60, 20, { stroke: "rgba(255,255,255,.2)", strokeWidth: 1.5, roughness: 2, fill: "none" });
```

**Pattern 2 — Star polygon + small circle:**
```javascript
// 10-point star: 5 outer points (r=18) alternating with 5 inner points (r=7)
// Center: (250, 35), start angle: -PI/2
var pts = [];
for (var j = 0; j < 10; j++) {
  var a = (Math.PI / 5) * j - Math.PI / 2;
  var r = j % 2 === 0 ? 18 : 7;
  pts.push([250 + Math.cos(a) * r, 35 + Math.sin(a) * r]);
}
rc.polygon(pts, { stroke: "rgba(255,255,255,.3)", strokeWidth: 2, roughness: 2.5, fill: "none" });
rc.circle(210, 70, 14, { stroke: "rgba(255,255,255,.2)", strokeWidth: 1.5, roughness: 2, fill: "none" });
```

**Pattern 3 — Dots cluster (3 circles):**
```javascript
rc.circle(240, 30, 16, { stroke: "rgba(255,255,255,.25)", strokeWidth: 1.5, roughness: 2, fill: "none" });
rc.circle(265, 45, 12, { stroke: "rgba(255,255,255,.2)", strokeWidth: 1.5, roughness: 2, fill: "none" });
rc.circle(225, 55, 10, { stroke: "rgba(255,255,255,.2)", strokeWidth: 1.5, roughness: 2, fill: "none" });
```

**Pattern 4 — Zigzag + circle:**
```javascript
rc.path("M 200 25 L 215 15 L 230 25 L 245 15 L 260 25", { stroke: "rgba(255,255,255,.25)", strokeWidth: 2, roughness: 2 });
rc.circle(280, 50, 18, { stroke: "rgba(255,255,255,.2)", strokeWidth: 1.5, roughness: 2.5, fill: "none" });
```

**SVG sizing:** The banner deco SVG uses `position: absolute; inset: 0; pointer-events: none; overflow: visible`. The coordinates assume the banner is approximately 300px wide by 120px tall. Use a viewBox matching banner dimensions to scale properly on different card widths.

5. Click handler uses `router.push(\`/courses/\${id}\`)` for navigation (404 until Phase 7)

## States

### Loading State
- Render 3 skeleton cards in the grid (matches 3-column layout)
- Each skeleton card: same outer dimensions as CourseCard
- Banner area: solid shimmer rectangle (120px height)
- Info area: 3 shimmer lines (term, grade row, progress row)
- Use existing `skeleton-shimmer` animation from globals.css

### Empty State
- Single centered message below title row
- BookOpen icon (48px, text-3 color) above heading
- Heading: "No Courses Yet" (Source Serif 4, 1.1rem, font-weight 600)
- Body: description text (Inter, 0.85rem, text-2 color)
- No CTA button (sync happens automatically)

### Error State
- RoughCard with orange-soft background
- Error icon (AlertCircle from lucide, orange color)
- Error message text
- No retry button (user refreshes page)

### Null Grade State (per card)
- Grade value: "\u2014" (em-dash) in text-3 color instead of course color
- Grade badge: hidden (do not render badge when grade is null)
- Progress bar: 0% filled (shows track only)
- Progress label: "0% assessed"
