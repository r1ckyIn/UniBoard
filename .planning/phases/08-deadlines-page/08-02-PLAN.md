- `viewMode: ViewMode` default "timeline"
- `filterMode: FilterMode` default "all"
- `selectedCourse: string` default "" (all courses)
- `expandedId: string | null` default null

**Data flow:**
- `useDeadlines()` — fetch all deadlines (no server-side filtering; filter client-side for responsiveness)
- `filteredDeadlines` = useMemo: filter by selectedCourse (if set), then by filterMode ("week" = days remaining <= 7 computed from due_date). Sort by due_date ascending.
- `courseOptions` = useMemo: extract unique course_codes from raw deadline data, map to { value: course_code, label: course_code }
- `upcomingCount` = filteredDeadlines.length (past-due excluded from count)

**Render pattern (same as CoursesPage):**
- AnimatedEntry around title row

- Error state: AlertCircle + t("errorMessage")
- Empty state: Calendar icon + t("emptyTitle") + t("emptyBody")
- Content state: if viewMode === "timeline" render DeadlineTimelineView; if "calendar" render a placeholder div with "Calendar view coming in Plan 03"

**Toggle handler for expandedId:** If clicking same id, collapse (set null); if different, expand that one.
