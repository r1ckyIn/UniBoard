**Change the outer div (line 97-103):**

Add `p-[10px]` to the outer div's className. The outer div currently has no padding, so the inner `bg-card-bg` div covers the rough.js border completely. Adding padding creates a visual gap where the hand-drawn border is visible.

FROM:
```tsx
<div
  ref={containerRef}
  data-testid="rough-card-outer"
  className={cn(
    "relative overflow-visible",
    "transition-shadow duration-[0.28s] ease-[cubic-bezier(.4,0,.2,1)]",
    !disableHover && "hover:shadow-card-hover hover:-translate-y-px",
    className
  )}
>
```

TO:
```tsx
<div
  ref={containerRef}
  data-testid="rough-card-outer"
  className={cn(
    "relative overflow-visible p-[10px]",
    "transition-shadow duration-[0.28s] ease-[cubic-bezier(.4,0,.2,1)]",
    !disableHover && "hover:shadow-card-hover hover:-translate-y-px",
    className
  )}
>
```

**Also add rounded corners to the inner div (line 109-113):**

The inner content div should have rounded corners to look intentional within the gap:

FROM:
```tsx
<div
  className={cn(
    "relative bg-card-bg shadow-card overflow-hidden",
    padding
  )}
>
```

TO:
```tsx
<div
  className={cn(
    "relative bg-card-bg shadow-card overflow-hidden rounded-[6px]",
    padding
  )}
>
```

**Important:** Many components pass `padding="py-[0px] px-[0px]"` to RoughCard (e.g., DigestHistoryCard, some course detail panels) because they manage their own internal layout. The 10px outer gap does NOT affect the inner padding prop -- it only creates space between the rough.js border and the inner bg div. This is the correct behavior.

After the change, run `cd frontend && pnpm test -- --run __tests__/design-system/RoughCard.test.tsx` to verify the RoughCard test still passes. Then run `cd frontend && pnpm build` to confirm no visual regressions in the build.
