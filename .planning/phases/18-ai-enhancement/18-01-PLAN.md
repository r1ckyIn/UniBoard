<objective>
Wire Ed Discussion thread sync to AI evaluation pipeline with batch limits and daily counter reset.

Purpose: INTEL-02 requires AI-extracted high-value information from Ed Discussion. The critical gap is that no sync task populates the discussion_threads table -- the existing sync_all_deadlines only extracts text for deadline detection. This plan creates the thread sync task, hooks it to post-sync AI batch evaluation, enforces the 20-thread batch limit (D-07), adds daily counter reset (D-09), and fixes the intelligence route to read pre-computed scores instead of calling AI inline.

Output: Working Ed Discussion sync -> AI evaluation pipeline, fully tested.
</objective>
