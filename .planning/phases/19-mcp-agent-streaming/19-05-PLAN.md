**Change 1: RoughCard border on review text output**
1. Add import: `import RoughCard from "@/components/design-system/RoughCard";`
2. The current review text display (line 107-111) is:
   ```tsx
   {reviewText && (
     <div className="bg-[#f6f5f0] border border-[#eae7e0] rounded-[10px] p-[16px] text-[0.82rem] text-[#2d2d2a] leading-[1.7] whitespace-pre-wrap">
   ```

   Replace this with:
   ```tsx
   {reviewText && (
     <RoughCard padding="py-[16px] px-[20px]" disableHover>
       <div ref={bottomRef} className="text-[0.82rem] text-[#2d2d2a] leading-[1.7] whitespace-pre-wrap">
         {reviewText}
       </div>
     </RoughCard>
   )}
   ```
   Remove the old `bg-[#f6f5f0] border border-[#eae7e0] rounded-[10px] p-[16px]` classes since RoughCard provides its own background (`bg-card-bg`) and border styling.

**Change 2: Page-level auto-scroll during streaming**
1. Add a ref for the bottom scroll anchor: `const bottomRef = useRef<HTMLDivElement>(null);`
2. Add a useEffect that triggers when `reviewText` changes AND `isStreaming` is true:
   ```tsx
   useEffect(() => {
     if (isStreaming && bottomRef.current && typeof bottomRef.current.scrollIntoView === 'function') {
       bottomRef.current.scrollIntoView({ behavior: 'smooth', block: 'end' });
     }
   }, [reviewText, isStreaming]);
   ```
   This scrolls the page so the bottom of the review text area stays visible as new tokens arrive.
3. Place `ref={bottomRef}` on the inner div inside RoughCard (the one containing `{reviewText}`), so scrollIntoView targets the text container's bottom edge.

Note: The `typeof ... === 'function'` check follows the jsdom safety pattern from CLAUDE.md (Problem 3: jsdom lacks scrollIntoView).
