    ```python
    class ToolExecutor:
        """Route MCP Agent tool calls to real platform adapters.

        Per D-13: Maps tool names to adapter methods.
        Per D-14: Requires decrypted tokens + course context.
        """

        def __init__(
            self,
            canvas_token: str | None,
            ed_token: str | None,
            course: Course,
        ) -> None:
            self._canvas_token = canvas_token
            self._ed_token = ed_token
            self._course = course
            # Adapters created lazily on first tool call that needs them
            self._canvas_adapter: CanvasAdapter | None = None
            self._ed_discussion_adapter: EdDiscussionAdapter | None = None
            self._ed_lessons_adapter: EdLessonsAdapter | None = None

        async def execute(self, name: str, input_data: dict[str, object]) -> str:
            """Execute a tool call and return text result for Claude."""
            # Route to appropriate adapter method
            if name == "search_canvas_modules":
                return await self._search_canvas(str(input_data.get("query", "")))
            elif name == "search_ed_threads":
                return await self._search_ed_threads(str(input_data.get("query", "")))
            elif name == "get_ed_lesson_content":
                return await self._get_ed_lesson(int(input_data.get("lesson_id", 0)))
            else:
                return f"Unknown tool: {name}"

        async def close(self) -> None:
            """Close all adapter HTTP clients."""
            if self._canvas_adapter:
                await self._canvas_adapter.close()
            if self._ed_discussion_adapter:
                await self._ed_discussion_adapter.close()
            if self._ed_lessons_adapter:
                await self._ed_lessons_adapter.close()
    ```

    Three private methods implementing tool execution:

    `_search_canvas(query: str) -> str`:
    - Guard: if `self._canvas_token` is None, return `"Canvas API token not configured. Please add your Canvas API token in Settings."`
    - Guard: if `self._course.canvas_course_id` is None, return `"No Canvas course linked."`
    - Lazily create `CanvasAdapter(api_token=self._canvas_token)` stored in `self._canvas_adapter`
    - Call `self._canvas_adapter.get_modules(self._course.canvas_course_id, include_items=True)`
    - Filter module items: match `query.lower()` against item titles and content (case-insensitive substring)
    - Format matching items as text: `"[Module: {module_name}] {item_title}: {item_content_preview}"` (truncate content to 500 chars)
    - Return formatted string, or `"No Canvas modules matched query: {query}"` if empty
    - Catch `TokenInvalidError` -> return `"Canvas API token is invalid or expired. Please update in Settings."`
    - Catch `(UpstreamUnavailableError, UpstreamAPIError)` -> return `f"Canvas API temporarily unavailable: {exc}. Try again later."`

    `_search_ed_threads(query: str) -> str`:
    - Guard: if `self._ed_token` is None, return `"Ed API token not configured. Please add your Ed API token in Settings."`
    - Guard: if `self._course.ed_course_id` is None, return `"No Ed Discussion course linked."`
    - Lazily create `EdDiscussionAdapter(api_token=self._ed_token)` stored in `self._ed_discussion_adapter`
    - Call `self._ed_discussion_adapter.get_threads(int(self._course.ed_course_id), limit=50)`
    - Filter threads: match `query.lower()` against `thread.title.lower()` and `thread.content.lower()`
    - Format matching threads: `"[Ed Thread #{thread.id}] {thread.title} (endorsed={thread.is_endorsed}): {thread.content[:500]}"`
    - Return formatted string, or `"No Ed threads matched query: {query}"` if empty
    - Same error handling as canvas

    `_get_ed_lesson(lesson_id: int) -> str`:
    - Guard: if `self._ed_token` is None, return `"Ed API token not configured. Please add your Ed API token in Settings."`
    - Lazily create `EdLessonsAdapter(api_token=self._ed_token)` stored in `self._ed_lessons_adapter`
    - Call `self._ed_lessons_adapter.get_lesson(lesson_id)`
    - Format: `"Lesson: {lesson.title}\n\nSlides:\n"` + join slide contents (truncate each to 1000 chars)
    - Same error handling as canvas
