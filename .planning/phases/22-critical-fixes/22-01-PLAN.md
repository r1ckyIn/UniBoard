<objective>
Migrate VoyageAI embedding calls from synchronous Client to native AsyncClient so they do not block the FastAPI async event loop.

Purpose: The synchronous `voyageai.Client.embed()` blocks the entire event loop for 200-2000ms per call, stalling ALL concurrent requests. The native `AsyncClient` uses aiohttp internally and yields control during network I/O.

Output: Updated `src/services/qa.py` with non-blocking embedding calls, plus test coverage verifying AsyncClient is used.
</objective>
