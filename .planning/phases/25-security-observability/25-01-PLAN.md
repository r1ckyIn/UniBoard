    Modify `src/web/main.py`:
    - Add imports: `import time` and `from structlog.contextvars import bind_contextvars, clear_contextvars`
    - Replace the existing `request_id_middleware` with a combined `access_log_middleware` that:
      1. Calls `clear_contextvars()` first
      2. Generates `request_id = str(uuid.uuid4())`
      3. Sets `request.state.request_id = request_id`
      4. Calls `bind_contextvars(request_id=request_id)`
      5. Records `start = time.perf_counter()`
      6. Calls `response = await call_next(request)`
      7. Computes `duration_ms = round((time.perf_counter() - start) * 1000, 2)`
      8. Logs `logger.info("http_request", method=request.method, path=request.url.path, status_code=response.status_code, duration_ms=duration_ms)`
      9. Sets `response.headers["X-Request-ID"] = request_id`
      10. Returns response
    - Add a new `security_headers_middleware` function (registered as `@application.middleware("http")`) that:
      1. Calls `response = await call_next(request)`
      2. Sets these headers on response:
         - `Strict-Transport-Security`: `max-age=63072000; includeSubDomains`
         - `X-Frame-Options`: `DENY`
         - `X-Content-Type-Options`: `nosniff`
         - `Referrer-Policy`: `strict-origin-when-cross-origin`
         - `Content-Security-Policy`: `default-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' https://*.supabase.co wss://*.supabase.co`
      3. Returns response
    - IMPORTANT middleware registration order: In FastAPI, middleware runs in reverse order of registration. Register security_headers_middleware AFTER the access_log_middleware so that security_headers_middleware runs AFTER access logging (which needs to run first to bind contextvars). The CORS middleware (add_middleware call) must remain FIRST so it handles preflight OPTIONS correctly.
