<objective>
Fix SSE streaming dual-path issue and add AI API key guard so AI features work correctly in production through the BFF proxy.

Purpose: Client-side SSE components (use-ai-stream.ts, UnitReviewSection.tsx) currently bypass the BFF proxy by reading NEXT_PUBLIC_API_URL and calling Railway directly from the browser. This causes CORS issues in production. Additionally, AI routes crash with 500 when ANTHROPIC_API_KEY is empty. This plan fixes both issues and includes a manual checkpoint for configuring the API key in Railway.

Output: SSE requests consistently route through BFF proxy; AI routes return 503 gracefully when unconfigured; ANTHROPIC_API_KEY set in Railway.
</objective>
