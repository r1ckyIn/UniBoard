Plans 01-02 created branded email templates (supabase/templates/), auth/confirm route handler, ForgotPasswordForm, UpdatePasswordForm, and updated RegisterForm for email confirmation flow.

User must complete the following manual dashboard configurations:

**Step 1 — Resend Account Setup:**
1. Go to https://resend.com and create an account (or sign in)
2. Go to Domains -> Add Domain -> enter your sending domain (e.g., `yourdomain.com`)
3. Resend will show DNS records to add (SPF TXT, DKIM CNAME records)
4. Add those DNS records at your domain registrar
5. Wait for verification (usually 1-5 minutes, up to 48 hours for DNS propagation)
6. Go to API Keys -> Create API Key -> copy the `re_XXXXXXXXX` key

**Step 2 — Supabase Dashboard SMTP Configuration:**
1. Go to Supabase Dashboard -> your project -> Auth -> SMTP Settings
2. Enable Custom SMTP
3. Enter:
   - Host: `smtp.resend.com`
   - Port: `465`
   - Username: `resend`
   - Password: paste the `re_XXXXXXXXX` API key from Step 1
   - Sender email: `UniBoard <noreply@yourdomain.com>` (use your verified domain)
   - Sender name: `UniBoard`

**Step 3 — Supabase Dashboard Email Templates:**
1. Go to Auth -> Email Templates
2. Edit "Confirm signup" template:
   - Subject: `Confirm your UniBoard account`
   - Body: Copy the HTML from `supabase/templates/confirmation.html` and paste it
3. Edit "Reset password" template:
   - Subject: `Reset your UniBoard password`
   - Body: Copy the HTML from `supabase/templates/recovery.html` and paste it

**Step 4 — Supabase Dashboard URL Configuration:**
1. Go to Auth -> URL Configuration
2. Set Site URL to your production Vercel URL (e.g., `https://your-production-url.vercel.app`)
3. Add to Redirect URLs:
   - `https://your-production-url.vercel.app/auth/confirm`
   - `https://uni-board-*-r1ckyins-projects.vercel.app/auth/confirm` (Vercel preview wildcard)
   - `http://localhost:3001/auth/confirm` (local dev)

**Step 5 — Enable Email Confirmations:**
1. Go to Auth -> General
2. Enable "Confirm email" toggle
3. Save

**Step 6 — Increase Rate Limits:**
1. Go to Auth -> Rate Limits
2. Set email sending rate to at least 30/hour (default may be lower)
