## Parser Fallback Strategy

| Field        | CSS class             | Header keywords (case-insensitive substring match) |
| ------------ | --------------------- | -------------------------------------------------- |
| due_date     | .assessment-due       | ["due", "deadline"]                                |
| length       | .assessment-length    | ["length", "word", "duration"]                     |
| description  | .assessment-description | ["description", "details"]                       |

Flow inside `_parse_row`:
1. Try CSS-class selector (existing behavior).
2. If result is empty, call `_extract_by_header_index(cells, headers, kws)`.
3. If no matching header or cell missing, return empty string (due_date becomes None via `due_text or None`).

## Deviations from Plan

### [Rule 1 - Spec drift] Wave 0 test stub shape

- **Found during:** Task 2 RED
- **Issue:** Wave 0 stub in `test_unit_outline_parser_fallbacks.py` used `outline = parser.parse(html); outline.assessments[0]` — but `parse()` returns `list[AssessmentItem]` directly (contract confirmed in `test_unit_outline_parser.py` and `test_outline_parser.py`). The `UnitOutlineParseResult` object is only returned by the async `fetch_and_parse` method.
- **Fix:** Changed the 2 Wave 0 tests to use `items = parser.parse(html)` and iterate `items[0]` directly. Matches existing parser contract — no production change needed.
- **Files modified:** tests/unit/test_unit_outline_parser_fallbacks.py
- **Commit:** d291421

### [Rule 3 - Blocking] CanvasAdapter lazy import blocked module-level type annotation

- **Found during:** Task 1 GREEN
- **Issue:** Existing code lazy-imported `CanvasAdapter` inside `sync_all_courses` function body. The new `_resolve_unit_outline_url` helper needs `CanvasAdapter` as a parameter type annotation, which must resolve at module load time.
- **Fix:** Moved `from src.adapters.canvas import CanvasAdapter` to module top-level imports. No circular import introduced (canvas.py does not import from sync).
- **Files modified:** src/sync/courses.py
- **Commit:** 0d184d1

### [Rule 3 - Blocking] Adapter lifecycle had to span upsert

- **Found during:** Task 1 GREEN
- **Issue:** Existing code closed `canvas_adapter` via try/finally immediately after `get_courses()`. But the resolver needs to make two more Canvas API calls (`get_tabs` + `get_external_tool`) during `_upsert_courses`. Closing the client too early would break the resolver.
- **Fix:** Restructured the try/finally so `canvas_adapter.close()` runs only after `_upsert_courses` completes. Net effect: single httpx.AsyncClient reused for courses + tabs + external_tool fetches per user, sharing rate limiter + circuit breaker state.
- **Files modified:** src/sync/courses.py
- **Commit:** 0d184d1

No Rule 2 (missing critical functionality) items. No Rule 4 (architectural) items. No auth gates.
