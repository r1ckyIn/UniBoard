<objective>
Implement SYNC-FIX-02: Canvas grades sync writes null scores because `GET /courses/:id/assignments` is called WITHOUT `include[]=submission`, causing Canvas to omit the `submission` field entirely. This plan adds an `include` kwarg to `CanvasAdapter.get_assignments` and uses it from the grades sync path.

Purpose: Currently `SELECT COUNT(*) FROM grades WHERE score IS NOT NULL` returns 0 after a successful sync. Fixing this is a 2-line core change + plumbing. Ensuring we do NOT break the deadlines sync (which also calls `get_assignments` but doesn't need submission data) requires the `include` parameter to be OPTIONAL.
Output: 1 kwarg added to `get_assignments`, 1 call site updated in `grades.py`, 2 test files flipped green.
</objective>

        self,

        *,
        include: list[str] | None = None,
    ) -> list[dict[str, object]]:
        """Fetch assignments for a course.

        Args:
            course_id: Canvas course ID.
            include: Optional list of `include[]` query parameter values.
                Common values: ["submission"] to embed per-user submission data

        if include:

        return await self._paginate(
