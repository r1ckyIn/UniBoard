<objective>
Implement SYNC-FIX-04: Canvas assignments with `due_at: null` are currently dropped due to a `str(None) == "None"` truthiness bug in `DeadlineService.aggregate_and_dedup`. The stringified "None" passes the `if not title or not due_str:` check, then `datetime.fromisoformat("None...")` raises ValueError and the loop `continue`s — silently losing everything that could reach the key-collision code path, resulting in only 1 deadline per course (the first dated assignment).

Purpose: Fixes the "Canvas 作业/截止日期同步完整性（不只抓到 1 条）" symptom described in the phase roadmap. This is a surgical 2-line fix but it unblocks ALL deadline data for courses with mixed dated/undated assignments.
Output: Replace truthy string check with explicit `isinstance` guard in 2 places in `deadline.py`.
</objective>
