<objective>
Add a "Resend email" button to the ForgotPasswordForm success state with a 60-second cooldown timer. Cooldown is component-local state (no server round-trip — Supabase already enforces server-side `max_frequency = "1s"`). The button shows "Resend in 00:NN" while disabled and "Resend email" when ready. On click, calls `useResetPassword().mutate(sameEmail)` and restarts the cooldown.

Since email confirmation is permanently OFF, the resend button is scoped to the password-reset flow ONLY (corrected from CONTEXT.md per research). The signup confirm flow has nothing to resend.

```tsx
const COOLDOWN_MS = 60_000;
const [cooldownEnd, setCooldownEnd] = useState<number | null>(null);
const [tick, setTick] = useState(Date.now());

useEffect(() => {
  if (!cooldownEnd) return;
  const id = setInterval(() => setTick(Date.now()), 1000);
  return () => clearInterval(id);
}, [cooldownEnd]);

const remainingMs = cooldownEnd ? Math.max(0, cooldownEnd - tick) : 0;
const inCooldown = remainingMs > 0;
const remainingSec = Math.ceil(remainingMs / 1000);
```

   - Start cooldown on initial mutation success: in the existing `useResetPassword` mutate's onSuccess (or via a useEffect on `mutation.isSuccess`), call `setCooldownEnd(Date.now() + COOLDOWN_MS)`.

   - Add a Resend button to the success-state JSX (below the existing "Back to sign in" link):

```tsx
<button
  type="button"
  onClick={() => {
    if (inCooldown || !submittedEmail) return;
    resetPassword.mutate(submittedEmail, {
      onSuccess: () => {
        setCooldownEnd(Date.now() + COOLDOWN_MS);
        toast.success(t("auth.forgotPassword.resendSuccess"));
      },
      onError: (err) => {
        toast.error(err instanceof Error ? err.message : t("auth.forgotPassword.resendFailed"));
        // Do NOT restart cooldown on failure — allow immediate retry
      },
    });
  }}
  disabled={inCooldown || resetPassword.isPending}
  className="mt-3 text-[0.84rem] font-medium text-[#d97757] hover:underline disabled:text-text-3 disabled:no-underline disabled:cursor-default"
>
  {inCooldown
    ? t("auth.forgotPassword.resendCooldown", { seconds: String(remainingSec).padStart(2, "0") })
    : t("auth.forgotPassword.resend")}
</button>
```
