## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-05-01 | Tampering | XSS via citation source titles | mitigate | React escapes children by default; rendering `{source.title}` as JSX child is safe. NEVER use the unsafe HTML injection prop for source content. Test with title containing `<script>` → assert escaped in DOM. |
| T-34-05-02 | Tampering | XSS via main_suggestion injection | mitigate | Source is server-generated LLM output; backend prompt prevents tool execution. Frontend renders as JSX child (escaped). Same React-default mitigation as T-34-05-01. |
| T-34-05-03 | Tampering | XSS via assessment_name in StudyRecCard | mitigate | React-default escaping. No HTML injection possible from JSX child rendering. |
| T-34-05-04 | Information Disclosure | Sources excerpt leaks neighboring user content | accept | RLS at backend (Plan 34-04 threat T-34-04-03) prevents cross-user retrieval. Excerpt is from user's own course. |
| T-34-05-05 | Tampering | remaining_credit_points form input bypass | mitigate | React `<input type="number" min={0} step={6} />` enforces client-side; backend Pydantic re-validates `Field(ge=0)` (Plan 34-03 threat T-34-03-01). Defense in depth. |
| T-34-05-06 | Repudiation | i18n key missing causes silent UX degradation | mitigate | Both en + zh JSON files updated atomically in same task. tsc fails if generated `useTranslations<'predict'>` keys reference missing names. |
