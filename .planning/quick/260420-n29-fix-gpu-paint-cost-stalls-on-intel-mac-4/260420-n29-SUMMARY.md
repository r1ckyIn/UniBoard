# Quick Task 260420-n29: Fix GPU Paint-Cost Stalls on Intel Mac Summary

Retrospective audit of a five-PR shipping event that eliminated the "window shrinks → becomes smooth / enlarges → gets choppy" (窗口越小越流畅) jank on Intel Mac by targeting four distinct viewport-area-proportional paint-cost subtypes plus a supporting CSP adjustment for local Supabase development. All 21 grep sentinels across 3 tasks passed against the current `main` checkout.

## Diagnostic Narrative — "Smaller Viewport = Smoother"

The decisive user clue across all four main fixes was **"窗口越小越流畅"** (smaller viewport = smoother). This signature is pathognomonic for GPU paint-cost bugs whose cost scales **O(w × h)** on the Intel Mac raster pipeline. The trap: `requestAnimationFrame` keeps ticking at 60 Hz even when the compositor has collapsed to 2-5 fps on-screen, so synthetic rAF / LoAF benchmarks declare everything "fine" while the user experiences an unusable page. These bugs only manifest on real-screen frame delivery under large viewport.

**Phase 37 anti-pattern we superseded:** A two-layer DOM + transform sidebar rewrite (rolled back in commit `9bab743` on a now-deleted branch) chased architecture when the real bug was a single CSS property on a **different** component (Header `backdrop-filter`, not Sidebar layout). The lesson: every fix in this family is "swap one CSS property, don't refactor." If you're writing architectural code (two-layer DOM, transform instead of width, React Suspense) you are targeting the wrong cost path — go back to diagnostic step 1.

**Diagnostic order** (fastest to slowest, stop at first resolution):
1. Grep `backdrop-filter|backdrop-blur` on full-viewport elements → drop blur, raise bg alpha.
2. Grep `shadow-\[` on fixed elements with animating width/height that bleeds OUTSIDE the `contain` box → replace with `border-*`.
3. Grep `animate-skeleton-shimmer` + `bg-[length:200%_100%]` + gradient on skeletons ≥ ~300 px × full-width → swap to `animate-pulse`.
4. Remove entry-fade (AnimatedEntry / opacity keyframes) on large elements (≥ ~500 k px² layer including shadow spread); keep on small ones.
