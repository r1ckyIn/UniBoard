# Quick Task 260423-i5k — Strip Markdown Code Fences in AIEngine

## Live bug (prod evidence)
Railway deploy logs, 2026-04-23 01:53-01:54 UTC, 5+ consecutive failures on
`21b487d`. Every single failure:

```
File "/app/src/services/ai_engine.py", line 125, in evaluate_thread
    data = json.loads(raw_text)
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)

ValueError: AI returned invalid JSON: ```json
{ "gpa_relevance": 0.8, ... }
```

Claude Sonnet sometimes wraps structured output in markdown code fences
(` ```json ... ``` `) despite system-prompt guidance. First character is
a backtick → `json.loads` blows up → `intelligence.evaluate_new_threads_ai`
loop aborts and no Ed thread gets a `gpa_relevance_score` written.

## Scope audit

`ai_engine.py` has **three** `json.loads` call sites that consume AI output:

| Line | Function | Current fence handling |
|------|----------|-----------------------|
| 125 | `evaluate_thread` | ❌ none — **live bug** |
| 194 | `generate_review` | ⚠️ inline regex fallback, only matches `{...}` (not arrays) |
| 223 | `score_urgency` | ❌ none — latent bug (array-shaped response) |

All three share the same root pattern. Fixing only one leaves two latent
landmines. Fix all three with a shared helper.

## Approach
Extract a module-level helper `_parse_ai_json(raw_text: str, *, context: str)`:

```python
_FENCE_OPEN = re.compile(r"^```(?:json)?\s*\n?", re.IGNORECASE)
_FENCE_CLOSE = re.compile(r"\n?\s*```\s*$")

def _parse_ai_json(raw_text: str, *, context: str) -> Any:
    """Parse a JSON payload from an AI response, tolerating markdown fences.

    Claude Sonnet occasionally wraps structured output in ```json ... ```
    despite prompting against it. This helper strips the fence (opening +
    closing, with or without the `json` language tag) and falls back to the
    bare text if no fence is present. Raises ValueError with a truncated
    sample of raw_text for debuggability on parse failure.
    """
    text = raw_text.strip()
    if text.startswith("```"):
        text = _FENCE_OPEN.sub("", text)
        text = _FENCE_CLOSE.sub("", text)
        text = text.strip()
    try:
        return json.loads(text)
    except json.JSONDecodeError as exc:
        raise ValueError(
            f"AI returned invalid JSON for {context}: {raw_text[:200]}"
        ) from exc
```

Replace the three call sites:
- `evaluate_thread`: `data = _parse_ai_json(raw_text, context="thread evaluation")`
- `generate_review`: `data = _parse_ai_json(raw_text, context="unit review")` (retires existing inline regex)
- `score_urgency`: `result = _parse_ai_json(raw_text, context="urgency scoring")`
