# UniBoard 前端设计灵感汇总 & Design Brief

## 一、整体美学方向：Claude/Anthropic 风格

这是贯穿整个设计的灵魂基调。

**关键词**：克制、温暖、纸张感、手绘线条、学术气质

### 色彩体系（来自 Anthropic 品牌）

| 色彩名称 | 色值 | 用途 |
|---------|------|------|
| 深近黑 | `#141413` | 主文字、侧边栏背景 |
| 米白 | `#faf9f5` | 页面主背景 |
| 暖橙 | `#d97757` | **品牌强调色**（高亮、按钮、重点标记） |
| 柔和蓝 | `#6a9bcc` | 辅助信息、图表、链接 |
| 橄榄绿 | `#788c5d` | 成功状态、进度完成 |

拒绝科技蓝紫霓虹，走"学术期刊 + 咖啡馆"的暖色路线。

### 质感与氛围

- 大量留白、柔和动效、不炫技、清晰可读
- 像一个安静但睿智的合作伙伴，而非花哨的 EdTech 产品
- 字体思路：工程精确感 + 古典温度，既有学术气质又不死板
- 更像智库而非创业公司，让人感到安静、可信赖

### 强调色策略

全站只用 **一种强调色**（暖橙 `#d97757`）做高亮，其余保持灰白底色，视觉和谐统一。

## 二、布局结构：三栏布局

| 左栏 | 中栏 | 右栏 |
|------|------|------|
| **窄侧边栏** | **主内容区** | **个人状态面板** |
| 圆形/圆角图标式垂直导航 | 课程、GPA、作业等核心内容 | Profile、日历、Todo、Activity |
| 深色或独立背景 | 米白/浅灰底色 | 卡片式模块堆叠 |
| 不占空间，简洁 | 宽度最大，焦点区域 | 信息密度高但有序 |

## 三、组件设计规范

### 3.1 卡片（Card）

- 圆角设计，统一圆角半径（建议 12-16px）
- **淡阴影（soft shadow）** 营造纸张浮起的立体感
- 背景用浅灰而非纯白，让阴影更自然
- 不同模块可用不同的 **低饱和度浅色背景** 区分身份

### 3.2 Todo / 任务列表

- 左侧 **竖线时间轴** 串联任务，有时间流动感
- 圆点标记当前/重要任务
- 每个任务卡片用不同浅色背景（浅红、浅黄、浅绿、浅蓝），低饱和度
- 紧凑但不拥挤

### 3.3 导航 & 筛选

- **侧边栏**：图标式垂直导航，hover 时展开文字
- **内容区分类**：横向标签栏（Tab bar），图标 + 文字结合
- **面包屑导航** 保持清晰层级

### 3.4 数据展示

- 图表用柔和色彩，圆角柱状图
- 进度条用品牌强调色
- 统计卡片（Total Courses、GPA 等）横排展示，简洁有力

## 五、设计定位（一句话）

> **"一个有纸张温度的 GPA 智能助手"** — 用 Anthropic 式的克制美学，让学生在安静、可信赖的界面中高效管理学业。不做炫技的 EdTech，做学生书桌上最顺手的那本笔记。
